# Neko Companion Web Bluetooth

Servire questa cartella via HTTPS (oppure `http://localhost`) e aprirla con una versione di Chrome/Edge che supporti Web Bluetooth.

```powershell
cd companion
python -m http.server 8080
```

Per inviare le credenziali Wi‑Fi: associare e cifrare la connessione BLE, quindi tenere premuto KEY sul dispositivo per aprire la finestra fisica di provisioning di due minuti. La pagina non memorizza la password.
