# Polyrhythmic Glider

Originali `polyNERO.png` e `polyBIANCO.png` forniti dall’utente il 25 novembre 2026.
L’importer usa la versione nera: rimuove soltanto i margini bianchi, mantiene le
proporzioni e converte il logo in bitmap nativa 160×40 a un bit, senza dithering.
`logo-display.png` è l’anteprima; `../../NekoBrandAssets.h` è la risorsa embedded.
Posizione sulla schermata Neko: x=12, y=16. La vista Orologio mostra solo l’ora.
