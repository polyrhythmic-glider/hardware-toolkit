# Examples and Tests

Questa cartella raccoglie il codice che non è il firmware principale:

- `hardware-tests/`: scanner I2C e test isolati MCP23017, NeoKey e LED;
- `legacy-four-oled/`: copia completa del vecchio `synthProject`, utile come riferimento e test autonomo;
- `esp32-e-lcd/`: progetti separati per display e-LCD/ST7305 e relativi esempi vendor.

Per la board combinata usare esclusivamente `../TheSynthProject/TheSynthProject.ino`.
