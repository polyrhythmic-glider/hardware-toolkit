# Polyglider Hardware Experiments

Repository sperimentale legata al progetto **Polyrhythmic Glider**.

Il contenuto sara' in continua evoluzione e potra' includere codice incompleto, test veloci, bozze tecniche e piccoli esperimenti hardware/software.

## Projects

- `dueENcoder/`: sketch Arduino per encoder/display.
- `synthProject/`: sketch Arduino synth, tracciato come progetto interno a `hardware-toolkit`.
